# 手柄图形素材

`joycon-left.png` / `joycon-right.png` / `joycon-pair.png` / `app-icon.png`
都是本项目自己用 AI 生图工具生成的，不是从任天堂或任何电商页面取来的产品图。
生成用的提示词在官网仓库的 `素材/prompt/`。

写下来是因为这几张图看起来像官方产品渲染图，上线前审查时会被当成来源可疑的素材
拦一次 —— 已经发生过。重新生成或替换时，请一并更新这份说明。

`hotspots.json` 定义每个按键在图上的位置，它是按键热区的权威来源（见
`docs/PRE-RELEASE-AUDIT.md` 的权威对照表）。

JoyHarness 与任天堂没有任何关联。Nintendo Switch 与 Joy-Con 是任天堂的商标，
本项目仅在描述兼容性时提及。
